# Karadzov Individual — GitHub Pages

Ова е готов статичен сајт. Не е потребно npm, build или backend.

1. Распакувај го ZIP фајлот.
2. Постави ги index.html, styles.css, script.js, .nojekyll и assets/ во коренот на GitHub репозиториумот. Не го поставувај ZIP фајлот како замена за нив.
3. Активирај GitHub Pages за гранката во која ги постави фајловите, со коренот на репозиториумот како извор.

Патеките до медиумите се релативни, па сајтот работи и на адреса со име на репозиториум.
Контактите и социјалните линкови се зачувани. Видеата се локални Full HD MP4 фајлови.
Најголемиот фајл е околу 21,3 MB. Ако ги поставуваш преку GitHub веб-интерфејсот, постави ги распакуваните фајлови, не целата архива.

Сајтот користи Noto Sans од Google Fonts, со локален fallback Arial/sans-serif.
